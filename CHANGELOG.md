# Changelog

## 0.1.0 — 2026-10-16

- Five distinct authored-raster workplace environments in a staggered Canvas world.
- Existing Everyday Office preserved; four new scenes, silhouettes and navigation profiles.
- Ten existing adult coworkers distributed once across the five environments.
- Long work sessions, independent gestures, furniture-aware routes, conversations and small briefings.
- Six intermittent ambient events per environment, respecting reduced motion.
- Campus overview fit, room navigation, hover and selection, with existing pan/zoom/reset.
- Tests for room distribution, activity routes, personal space and simulated shifts.

Live browser automation remains unverified due to the available browser tool's
access-policy failure. Mathematical interaction checks and actual Canvas renders
were checked separately. Cross-room walking and full directional character animation
are not implemented; characters work within their assigned environments.
